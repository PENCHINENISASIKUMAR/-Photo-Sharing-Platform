# \# PhotoShare

# 

# A full-stack photo sharing platform for event photography teams to collaborate, curate, and deliver galleries to clients.

# 

# \## Features

# 

# \- 🔐 Role-based accounts (Admin / Team Member)

# \- 📸 Multi-file photo upload with drag \& drop and live progress

# \- 🎯 Curated gallery selection (Admin picks photos to deliver)

# \- 🔒 PIN-protected client galleries (6-digit PIN)

# \- 🔗 Shareable gallery links

# \- 👥 Team member assignment per event

# \- 🌙 Modern dark UI with animations

# \- 🗄️ PostgreSQL / SQLite support

# \- ☁️ Deploy-ready for Render / Heroku / Railway

# 

# \## Tech Stack

# 

# \- \*\*Backend:\*\* Flask, SQLAlchemy, Flask-Migrate, Flask-Bcrypt

# \- \*\*Database:\*\* PostgreSQL (production) / SQLite (dev)

# \- \*\*Frontend:\*\* Vanilla JS, HTML, CSS

# \- \*\*Deploy:\*\* Gunicorn + Render / Heroku
